# Naveen's Manifesto - NMIT ISE Forum

A modern, professional, and responsive manifesto website built for Naveen's candidacy in the NMIT ISE Forum. The platform highlights the candidate's core vision—"Events That Inspire"—alongside key initiatives in a clean, minimalist design optimized for both mobile and desktop experiences.

## Features
- **Hero Section**: Impactful landing area introducing the candidate and core message.
- **Vision & Initiatives**: Clear presentation of goals, objectives, and planned activities.
- **Responsive Design**: Built with a mobile-first approach ensuring a seamless experience across all devices.
- **Modern UI**: Clean typography, subtle animations, and institutional branding.

## Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Getting Started

Follow these steps to run the website locally:

1. **Install Dependencies**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   To create an optimized production build:
   ```bash
   npm run build
   ```

## Project Structure
- `src/App.jsx`: Main application layout combining all sections.
- `src/components/`: Reusable specific sections like `Navbar`, `Hero`, `Vision`, `Initiatives`, `CallToAction`, and `Footer`.
- `tailwind.config.js`: Tailwind configuration including custom colors (e.g., brand blues).
